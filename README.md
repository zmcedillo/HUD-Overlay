# HUD Overlay

**HUD Overlay** is a Python-based desktop application designed to overlay custom game HUDs directly onto Nintendo DS emulator windows. The application utilizes a dual-window architecture consisting of a primary Control Panel and an invisible Overlay Window.

**Key Features:**

* **Control Panel Window:** Acts as the central hub for managing the overlay canvas.
* **Dynamic Resizing & Positioning:** Fully adjustable canvas dimensions to align precisely with any emulator layout.
* **JSON Configuration Support:** Natively loads and exports saved layout configurations.
* **DS Screen Toggling:** Seamlessly switches HUD elements between the top and bottom Nintendo DS screens.
* **Canvas Locking:** Includes a lock toggle to freeze the overlay window position, preventing accidental dragging during gameplay.
* **Element Management:** Allows users to show, hide, delete, or reorder individual HUD elements on the fly.

* **Invisible Overlay Window:** A transparent canvas that renders the HUD assets directly over the emulator. It can be freely dragged and positioned anywhere on the screen when unlocked.
